# Biblioteca
## Ferramentas utilizadas: 
- [Poetry](https://python-poetry.org/) `Gerencia dependências do python`
- [Django](https://www.djangoproject.com/) `Será responsável por controlar regras de negócio do backend`
- [Django REST framework](https://www.django-rest-framework.org/) `Interface de API Rest para o frontend`
- [Django Extensions](https://django-extensions.readthedocs.io/en/latest/index.html) `Utilitário para o django ex: cli, fields, mixin models, ebugging, etc.`
- [DRF Spectacular](https://drf-spectacular.readthedocs.io/en/latest/) `Documentação da API Rest`
- [VueJs](https://vuejs.org/) `Ferramenta de desenvolvimento frontend com componentes`
- [Tailwind](https://tailwindcss.com/) `Ferramenta de estilização frontend com base em classes css`
- [Daisyui](https://daisyui.com/) `Biblioteca de componentes prontos baseado em tailwind`
- [TanStack Query](https://tanstack.com/query/latest) `Gerencia estados reativos ao chamar requisições HTTP(S)`
- [Axios](https://axios-http.com/ptbr/docs/intro) `Gerencia chamadas HTTP(S) de forma mais eficiente`
- [Django Vite](https://github.com/MrBin99/django-vite) `Integra o Django com o frontend Vue ao usar o vite para servir os aquivos estaticos`
